# License decision required

STEP 9A does not grant an open-source license automatically.

Before the first public push, the authors must confirm:

1. whether Chonnam National University or the research group has an
   intellectual-property or software-release policy;
2. whether all authors approve the selected software license;
3. whether third-party baseline implementations impose additional notice or
   attribution obligations.

Recommended candidates for a research-code repository include MIT,
BSD-3-Clause, or Apache-2.0, but no option is selected by this release step.

Until a final `LICENSE` file is added, the repository remains unlicensed and
redistribution rights are not granted.
