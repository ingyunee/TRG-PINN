# Internal naming policy

The public method name is **TRG-PINN**.

Historical research artifacts may retain internal labels such as:

```text
tpinn
tPINN
tpinn_all
checkpoint_tpinn
```

These names are preserved when changing them would break checkpoint, cache, or
source-hash provenance. They do not denote a different method.

Manuscript text, figure labels, README content, and user-facing comparison
outputs use `TRG-PINN`.
